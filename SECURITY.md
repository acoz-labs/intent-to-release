# Security

Intent to Release v0.1 is a passive Markdown-and-JSON plugin. It contains no MCP
server, app, executable plugin script, hook, network integration, telemetry,
credential, or hosted service. Installing it grants no runtime authority beyond
Codex reading its skills, references, and templates.

Report suspected credential, private identifier, inaccessible-link, or history
exposure privately to the repository maintainers before opening a public issue.
Do not include the sensitive value in a report. Public derivatives should run
the deterministic boundary checks and receive independent semantic review.

Public projection uses generic structural secret/path classes plus a mandatory
untracked candidate denylist decision. Diagnostics identify only a redacted rule;
they never print matched content. Release receipts bind immutable candidate,
repository, ref/object, hosted-surface, authority, event, tag, and anonymous
installation evidence; environment assertions alone are not release authority.

The projected content manifest contains no private source identity, candidate-
specific terms, or reviewer material. Those fields are bound in a private
receipt outside the public tree. Projection rejects symlinks, gitlinks, special
files, traversal, and undeclared executable modes, and validates the committed
SHA-1 tree against every manifest entry.

Model-forward validation uses a new disposable Codex home containing only
copied authentication and generated plugin registration. It disables repository
rules and persistent sessions, uses public-only fictional prompts, retains raw
responses only as private temporary evidence, and commits at most digest/rubric
metadata.
