# Intent to Release Plugin

Three focused skills guide one lifecycle:

- `$intent-to-release-discover` shapes opportunity and Gate 1.
- `$intent-to-release-design` creates the plan and Gate 2.
- `$intent-to-release-deliver` implements through release within the approved envelope.

Read [the normative method](references/method.md), copy templates from `assets/templates/`, and use the fictional [Paper Airship example](references/example/README.md) as an end-to-end orientation.

The installed payload is passive Markdown and JSON. It has no credentials, network integration, telemetry, executable hook, MCP server, or app.
