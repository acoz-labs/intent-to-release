# Adoption and Privacy

Start with one change. Map the six artifact owners in the method onto artifacts your repository already uses, add exactly two explicit product-authority decisions, and preserve existing review/release controls. Shorten templates to fit risk; do not rename every existing workflow concept.

Before sharing a derivative, review the current tree and complete history for private names, accounts, paths, hosts, project data, credentials, inaccessible links, and hidden tooling assumptions. Use invented examples. Keep candidate-specific search terms outside the public product. Require a second person to perform semantic review; a denylist alone cannot recognise meaning.

This plugin is passive: it includes Markdown and JSON only. It needs no credential, makes no network request, collects no telemetry, executes no hook, and provides no MCP server, app, or custom UI.
