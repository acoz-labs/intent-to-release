# Conversation Reference

Intent to Release began as a response to ad hoc prompt-to-PR work: agents can produce code quickly, but speed does not decide whether a change is worthwhile, safe, understood, or accepted.

The method makes five principal choices: three focused phases; exactly two human product-authority gates; one owner for each kind of knowledge; temporary design reconciled into shipped docs; and one immutable candidate independently accepted before release.

The loop is: shape an ambiguous opportunity into a brief; approve intent at Gate 1; design against the actual repository; approve the plan and execution envelope at Gate 2; implement and test; reconcile drift and delete temporary plans; obtain independent review; accept the exact candidate; promote without rebuilding; verify and retain rollback evidence.

This summary is explanatory. [The method](method.md) is normative.
